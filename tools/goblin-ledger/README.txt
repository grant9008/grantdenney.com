GOBLIN LEDGER
Auction house prices, charts and price advice inside WoW Forever.
Prices are for the Alliance auction house on the US PvP realms.
More: https://grantdenney.com/goblin-ledger/

INSTALL (Windows, about 3 minutes)
1. Unzip first: right-click GoblinLedger.zip, Extract All, Extract.
2. In the unzipped folder, double-click Install-Goblin-Ledger.bat.
   Windows may warn you ("Windows protected your PC"): click More info,
   then Run anyway. If it asks "Open File - Security Warning", click Run.
3. The installer finds WoW Forever. If it cannot, it asks you to paste the
   game folder: in the Battle.net app click the gear next to Play, choose
   Show in Explorer, open the _forever_ folder, click the address bar,
   press Ctrl+C, then click the installer window, press Ctrl+V and Enter.
4. It copies the addon and downloads the latest prices. When it asks
   "Update prices automatically every 30 minutes?", press Y and Enter.
5. Start WoW Forever (close it fully first if it was open). Hover an item
   you could sell: the Goblin Ledger lines show its prices.
   Type /gl help in chat for the commands.

Afterwards you can delete the zip and the unzipped folder. (Unzipped it
straight into the game's AddOns folder? Then delete only the zip.)

FRESH PRICES
They update by themselves every 30 minutes while you are logged in to
Windows (if you said Y). The game loads them when you log in or type
/reload. Want fresh prices right now? Run Install-Goblin-Ledger.bat again.

NEW VERSION
Download the zip again, unzip it and run Install-Goblin-Ledger.bat.

NOT WORKING?
- "Windows did not allow copying into the game folder": right-click
  Install-Goblin-Ledger.bat and choose Run as administrator.
- No prices in game: close WoW fully and start it again. At the character
  screen click AddOns and make sure Goblin Ledger is ticked.

REMOVE IT
Double-click Uninstall-Goblin-Ledger.bat and press Y. It removes the addon,
the price updater and the "Goblin Ledger Prices" task. It asks before
deleting your saved settings.
