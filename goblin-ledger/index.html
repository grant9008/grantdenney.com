Goblin Ledger

Auction house prices and handy tips, right in your WoW Forever tooltips.

Download for Windows

Free. Version 1.1.0. Alliance, US PvP realms.

Install

  1. Download the zip

    Browser asks? Keep.

  2. Unzip it, double-click Install-Goblin-Ledger.bat

    Windows warns? More info, Run anyway.

  3. Press Enter twice, start WoW

    Hover an item: prices are there.

Had 1.0.0? Do it again once. Keep the unzipped folder.

On your phone? Install it from your Windows PC.

Commands
  • /gl help every command
  • /reload load the new prices
  • /gl compact one-line tooltips
  • /gl chart Linen Cloth chart any item
  • /gl watch Runecloth add to watchlist
  • /gl flips flip ideas in chat
  • /gl bags cleanup list in chat
  • /gl boat now boat just docked: learn it
  • /gl update your version, how to update
Not working?
  • Close WoW fully and start it again.
  • Character screen: AddOns, tick Goblin Ledger.
  • Can't copy? Right-click the installer, Run as administrator.
  • To remove it: Uninstall-Goblin-Ledger.bat.
